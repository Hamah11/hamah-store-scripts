# الكاش والتحقق في زد — القواعد التي تمنع «التعديل لم يظهر»

## 1) أنواع الكاش التي واجهناها
| ماذا | المدة | كيف يُتجاوز |
|---|---|---|
| صفحات المتجر (الرئيسية، المنتجات) — Souin/Redis، `cache-control: s-maxage=300` | ~15 دقيقة لكل نوع متصفح، وقد يُقدَّم القديم حتى ~25 دقيقة | لا يُتجاوز بـ `?r=`. الفحص بطلب `curl` بـ User-Agent عشوائي، والنظر إلى ترويسة `age` و`cache-status` |
| ملف JS الثيم على CDN (`custom-scripts.js?v=…`) | النشر يتأخر دقائق؛ صفحات المنتجات تطلب `?v=` قديمًا حتى يُحفظ منتج أو ثيم | اجلب الملف برقم `?v=` عشوائي جديد للتأكد من الحفظ؛ ثم احفظ منتجًا (غيّر حرفًا في وصف السيو وأعده) لتجديد الصفحة. غيّر `var hv=N;` لإجبار النشر |
| صفحات المنتج بعد حفظ المنتج | ~10 دقائق | انتظار |
| صفحات المدونة `/blogs/…` | قد تبقى على نسخة قديمة حتى مع `cache-status: uri-miss` (نسخة مخزّنة عند زد نفسها) | انتظار يوم؛ وإلا دعم زد: «صفحات المدونة تعرض CSS قديمًا رغم نشر الإعدادات العامة، نرجو مسح الكاش للمتجر <رقم>» |
| GitHub raw / jsDelivr على `main` | حتى 12 ساعة | استخدم commit SHA الكامل دائمًا |
| محرر «تعديل JS» في زد | قد يعرض نسخة قديمة | المصدر ملف GitHub لا المحرر |

## 2) كيف نتفادى المشكلة أصلًا في متجر جديد (منارات)
1. ضع CSS في الحقل الصحيح **وفي سجلّي layout.twig معًا** قبل إنشاء صفحات المدونة والصفحات الثابتة.
2. ضع JS الثيم النهائي (مع بيانات الجمعية) مرة واحدة قبل نشر الفرص.
3. اضبط عنوان ووصف الرئيسية (بلا «متجر») قبل إرسال sitemap وطلب الفهرسة.
4. بعد كل تغيير: تحقق من الحفظ أولًا (المسودة/المنشور أو ملف CDN)، ثم انتظر الكاش، ثم افحص الموقع الحي. لا تعدّل مرة ثانية قبل اكتمال هذه الخطوات.

## 3) أوامر التحقق الجاهزة
```bash
# صفحة من الموقع الحي بدون كاش المتصفح (استبدل النطاق والمسار)
curl -s -D - -A "Mozilla/5.0 $RANDOM" https://<domain>/<path> -o /tmp/p.html | grep -i '^age:\|cache-status'
grep -c 'hg-flag{' /tmp/p.html        # 1 = الشريط الجديد موجود
grep -c 'header::before' /tmp/p.html  # 0 = لا أثر للشريط القديم
grep -c 'متجر' /tmp/p.html            # 0 مطلوب في العنوان والوصف

# ملف JS الثيم من CDN بنسخة جديدة
curl -s "https://<cdn>/custom-scripts.js?v=$RANDOM" | grep -o 'var hv=[0-9]*'
```
في متصفح المستخدم (تبويب تخصيص القالب):
```js
// معرّفات الثيم والملفات
const v=document.querySelector('#app').__vue__.$data; [v.themeId, v.themeFiles.map(f=>[f.id,f.name])]
// المنشور (draft=0) مقابل المسودة (draft=1)
```

## 4) قاعدة الحكم
- «Saved successfully» ليس دليلًا. الدليل: القيمة محفوظة عند إعادة الفتح + الموقع الحي بعد الكاش + لقطة شاشة.
- إذا كانت الصفحة الحية قديمة و`age` كبير → كاش، انتظر. إذا كانت قديمة و`age` صغير أو `uri-miss` ولا تزال قديمة بعد ساعة → مصدر آخر (سجل ثانٍ، أو كاش عند زد) لا خطأ في الحفظ.
