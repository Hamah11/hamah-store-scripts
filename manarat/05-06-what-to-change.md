## أين يُوضع كل ملف (التفصيل في الملف 02 القسمان 4 و5)
- JS: اللوحة → الثيمات → ⋮ → تعديل JS → استبدال كامل → حفظ → تحقق من CDN بـ `?v=` عشوائي.
- CSS: تخصيص القالب → «الرئيسية ▾» → «إعدادات عامة» → «كود Css الخاص» بطريقة `window.activeForm` + حدث input + انتظار + «حفظ»، **ثم** السجل الثاني في layout.twig بطلب POST مباشر. تحقق من المنشور بـ `draft=0`.
